# Contributing

## Add Or Revise An Event

1. Start from `data/proposals/proposal.template.json`.
2. Write the smallest factual claim that the cited evidence supports.
3. Prefer original sources where available.
4. Put analysis in `interpretation`, not in `summary`.
5. Record disagreement in `disputes`.
6. Run `npm run check`.
7. Request human review before moving a proposal into a published timeline.

## Review Checklist

- Does every factual claim have a source?
- Is the source type accurate?
- Is the event date no more precise than the evidence allows?
- Is interpretation clearly separated from observed fact?
- Are competing claims or missing evidence visible?
- Does a private source remain private unless publication was explicitly approved?
- Does the generated timeline still build?
